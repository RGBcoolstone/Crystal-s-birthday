CRYSTAL'S BIRTHDAY WEBSITE
==========================

HOW TO OPEN
1. Extract this folder.
2. Open the folder in VS Code.
3. Double-click index.html, or use the Live Server extension in VS Code.

ADDING PHOTOS
Put your own pictures in the images folder using these exact names:
- crystal-1.jpg
- crystal-2.jpg
- crystal-3.jpg

You can use .png or .webp too, but if you change the extension, update the matching filename in index.html.

ADDING A VIDEO
Put a video named crystal-memory.mp4 in the videos folder.
For best performance, use a compressed MP4 rather than a very large phone video.

EDITING THE MESSAGE
Open index.html and find the section marked "A LITTLE NOTE FROM ME TO YOU". Edit the paragraphs to make the message more personal.

BIRTHDAY COUNTDOWN
The countdown automatically targets the next October 29, so you won't need to update the year each time.

PUBLISHING
You can publish this as a static site with GitHub Pages. Remember that any photos/videos you add to a public repository may be visible to anyone visiting the site.
